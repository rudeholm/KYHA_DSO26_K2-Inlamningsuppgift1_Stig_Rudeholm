#### Version 1.1 använder en del specialtecken som inte visas korrekt i Visual Studios terminalfönster, t.ex. dubbelt utropstecken `‼` för att representera dubbelparkerade motorcyklar. I ett separat Windows PowerShell terminalfönster bör det dock fungera. `dotnet run` räcker för att köra programmet.

I båda versionerna kan alla funktioner nås från huvudmenyn, inkl. de automatiska testerna.

Tryck `Esc` i huvudmenyn i v1.1 för att visa specialmenyn som även inkluderar ett demoläge med en enkel simulation där fordon parkeras och hämtas ut slumpmässigt.
